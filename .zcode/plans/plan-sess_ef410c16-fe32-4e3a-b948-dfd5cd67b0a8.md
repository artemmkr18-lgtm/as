# Плоский худ 1в1 по референсам (5 фото ksnip)

## Что не так сейчас
`HUD.java` оброс «иишным» стилем: радиусы 10–11, акцентные вертикальные полоски у каждой строки, иконки в каждой строке биндов, свечения/градиенты. Референсы — плоские тёмные плашки, компактные строки, ничего лишнего.

## Общий стиль — новые константы в `HUD.java`
- Фон: `#1E1E22` (rgb 30,30,34), плотный, без блюра/теней
- Радиус: `7f` (у чипов/пилюль 5f)
- Текст: белый основной, приглушённый серый для второстепенного (fps-лейбл, дефолтные таймеры)
- Акцент: `getAccent()` → тема-цвет awd `#C21B85` (бинды, чипы, полоски, бейджи)
- Пилюли таймеров: баффы — тёмно-серо-синий фон + светлый текст; дебаффы (яд) — зелёная пилюля как на фото
- Убрать: textGlow/glow, многоцветные градиентные rect, полоски-акценты у строк, иконки в строках биндов

## Элементы по фото

1. **Карточка игрока (новая, опция «Игрок»)** — фото 1, top-left дефолт: тёмная плашка, слева голова со скина (`drawPlayerHead` уже есть в TargetHUD), ник белым, иконка пинга + пинг, HP, снизу тонкая полоска здоровья (3–4 px, акцент темы, длина = hp/20). Новый `HudDrag("PlayerCard", 6, 6)` + опция в `MultiListSetting`.

2. **Ватермарка → нижняя пилюля** — фото 2: маленький акцент-бейдж с логотипом слева, иконка user + ник, gauge-иконка + `N`+`fps`, clock-иконка + `HH:mm`. Дефолт — слева снизу (`place(w, h, bottomInset)` уже есть). Убрать вложенный лого-бокс.

3. **Binds** — фото 3: хедер «Binds» + маленький акцент-чип справа, тонкий разделитель под хедером, строки: имя белым слева, бинд акцентом справа. Без иконок модулей и полосок. Строки компактнее (~19px).

4. **Cooldowns** — фото 4: хедер «Cooldowns» + маленькая звёздочка-иконка акцентом справа; строки: имя предмета + время в muted-пилюле radius 5.

5. **Зелья** — фото 5, top-right: строки со скруглённым слотом иконки эффекта (~20×20), русское имя белым, справа пилюля длительности (бафф — серо-синяя, дебафф — зелёная).

6. **Остальные (TargetHUD, Стафф, Инфо, Броня, Уведомления)** — те же константы: плоский фон, radius 7, чипы/полоски в едином стиле, акцент = тема. Данные и логика не трогаю, только визуал.

## Не трогаю
Drag-систему (`HudDrag`), сохранение позиций в config.properties, темы, Module-систему. Сохранённые позиции юзера остаются валидны.
